# Changelog

All notable changes to Voice-Agent are documented here.

## [0.1.0] - 2026-09-14

### Added

- Next.js, React, and TypeScript application foundation
- Shared UI primitives and Tailwind CSS setup
- Voice-Agent problem statement and product brief
- Product metadata for real-time conversational AI
- Local agent skill references for future implementation work

### Status

This is a foundation release for the private application repository. It is not
an npm package release and does not claim that the real-time voice runtime or
Moss retrieval layer is production-ready.
